Site policy

Privacy

Plain-language information about what this website currently does — and does not — collect.

Current build

Effective September 3, 2026.

This policy should be updated whenever the site adds forms, analytics, newsletters, advertising technology or other data-processing services.

No advertising or analytics trackers in the current site code

The current Sierra Leone To The Top website does not include advertising pixels, third-party analytics scripts, user accounts or onsite tracking cookies. We are deliberately starting simple.

Hosting and basic technical data

The site is designed to be hosted through GitHub Pages. Like most web-hosting infrastructure, the hosting provider may process technical request information needed to deliver and secure the service. That processing is governed by the provider’s own policies rather than by custom tracking code added by Sierra Leone To The Top.

Site search

The website’s search feature uses a static index downloaded with the site and performs matching inside your browser. Sierra Leone To The Top does not send search terms to a search provider, analytics service or advertising platform in the current build.

RSS and JSON feeds

The site may publish public RSS and JSON feeds containing story titles, summaries, categories, dates and public article links. These feeds do not contain subscriber profiles or private reader data.

External links

The site links to external services such as YouTube, X and source websites. If you follow an external link, that service may collect information under its own privacy policy. Sierra Leone To The Top does not control the data practices of external sites.

Story leads and communications

The current website does not operate an onsite submission form. If you choose to contact Sierra Leone To The Top through an external social platform, information you send is handled through that platform. When a permanent domain email or submission system is introduced, this policy will be updated to explain how those communications are handled.

Children

This site is a general public information and media platform. It is not designed to collect personal information directly from children through accounts or forms.

Changes to this policy

New functionality can change privacy practices. We will revise this page when material data-collection features are introduced rather than leaving an outdated policy in place.
